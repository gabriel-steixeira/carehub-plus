# Workflow: Run Application & Emulator

## Trigger
User says: "roda o app", "iniciar emulador", "rodar no emulador", or "testar app"

## Steps (execute in order)

### Step 1 — Check Emulators
- Run `flutter emulators` to list all available virtual devices in the system environment.

### Step 2 — Launch CareHub Emulator
- Run `flutter emulators --launch carehub_emulator` to launch the Android emulator.

### Step 3 — Run Application
- Run `flutter run` to start building and executing the CareHub+ Flutter application.
